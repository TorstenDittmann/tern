Agent API and MCP

Let your agent test what it just built.

Coding agents open, click, type and read real tabs through the tern CLI or its MCP server. A purple ring shows which tab they're driving.

$ tern tabs open localhost:5173/checkout --wait idle
$ tern page snapshot
textbox "Email" e3   button "Continue" e7
$ tern page type e3 "ada@example.com"
$ tern page click e7
$ tern console read --level error
[error] POST /api/address 422
  • One line for Claude Code.claude mcp add tern -- /Applications/Tern.app/Contents/Helpers/tern mcp
  • Real input.Clicks and key presses are real macOS events, so pages see trusted input.
  • Logs included.Console output and fetch or XHR requests are captured for every tab.
  • Local only.Off until you turn it on. A private Unix socket, no network port.

Privacy

Private before you
change a setting.

Ads and trackers are blocked from the first page you open, using native WebKit content rules that cost the page almost nothing.

The link you clicked

shop.example.com/item/42?color=slate&utm_source=newsletter&fbclid=IwAR2xK9

The page Tern loads

shop.example.com/item/42?color=slate

Blocking, built in EasyList and EasyPrivacy, on by default. Third-party pings are dropped.
Your dev server just works localhost, *.test and *.local are left alone. One command turns blocking off for any site.
Sites ask first Camera, microphone and location need your OK, and you can make Tern remember it per site.

Tech specs

Size

Under 1 MB, release build.

No Electron, no bundled Chromium.

Engine

WebKit, through WKWebView, in plain AppKit and Swift.

One shared data store for every tab, so WebKit reuses its processes and caches.

Requires

macOS 15.4 or later.

To build: Xcode 16.3 or later and XcodeGen.

Extensions

Safari Web Extensions, plus unpacked MV2 and MV3 extensions.

Native messaging is not supported.

Automation

JSON-RPC over a local Unix socket, the tern CLI, and an MCP server.

License

MIT. Free and open source.

Build it in
about a minute.

There are no signed releases yet, so you build Tern from source. You'll need Xcode and XcodeGen.

Open the repositoryReport an issue
$ brew install xcodegen
$ git clone https://github.com/TorstenDittmann/tern.git
$ cd tern
$ make release

Tern is early and moving fast. It works as a daily browser, but there are no prebuilt releases yet. Ad and tracker blocking uses the EasyList and EasyPrivacy filter lists.
